# TASB Legacy Archive

This directory contains the pre-RoPE-fix TASB stack, preserved for provenance only. The original capture pipeline sampled from pre-RoPE `q_proj`/`k_proj` projections — the wrong J matrix. Because HF LLaMA applies rotary position embeddings between projection and the attention matmul, the reconstructed QK scores in legacy code correspond to a different energy landscape than the captured post-softmax weights. Confirmed by `tests/test_rope_regression.py`: pre-RoPE reconstruction max diff vs HF attention weights = 0.0988 (structurally wrong). All numerical results from legacy code — match rates, η scores, encoding-equivalence findings — are invalid as bridge-faithfulness evidence. The canonical bridge stack is in the repository root: `tasb_capture_v2.py`, `tasb_sampler_v2.py`, `tasb_injector_v2.py`, `tasb_pipeline_v2.py`.
